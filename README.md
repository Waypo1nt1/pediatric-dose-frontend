# Расчёт детской дозы препарата – фронтенд

Одностраничное приложение на React 19, TypeScript и Vite 8. Компоненты интерфейса – React-Bootstrap,
маршрутизация – React Router. Данные берутся только из коллекции mock-объектов `src/modules/mock.ts`,
бэкенд не используется. Redux и Context не применяются.

Запуск: `npm install`, затем `npm run dev`. Приложение открывается по адресу http://localhost:5173,
стартовый маршрут ведёт на плитку.

## Плитка доз препаратов – `/drug_doses`

Список опубликованных доз препаратов в две колонки.

| Элемент | Назначение |
| --- | --- |
| Ползунок «от» | нижняя граница фильтра по взрослой дозе, 0–1000 мг, шаг 10 |
| Ползунок «до» | верхняя граница фильтра по взрослой дозе, 0–1000 мг, шаг 10 |
| Кнопка «Найти» | применяет фильтр и пересобирает список доз препаратов |
| Карточка дозы препарата | изображение, название, взрослая доза, количество лайков; открывает ленту с этой дозы препарата |

## Лента доз препаратов – `/drug_doses/feed/:drug_dose_id`

Одна доза препарата поверх зацикленного видео. Без идентификатора открывается первая из коллекции.

| Элемент | Назначение |
| --- | --- |
| Видео | проигрывается автоматически, без звука |
| «Взрослая доза» | рекомендованная разовая доза для взрослого, мг |
| «Максимум в сутки» | максимальная суточная доза, мг |
| Счётчик лайков | количество лайков дозы препарата |
| Кнопка «Далее» | переход к следующей дозе препарата |
| Кнопка «ещё» / «свернуть» | разворачивает описание, свёрнутое до двух строк |

## Нижняя навигационная панель

Четыре пункта: «Лента», «Добавление», «Плитка», «Вход». Доступны «Лента» и «Плитка», остальные два
появятся в шестой лабораторной вместе с авторизацией и добавлением доз препаратов.

## Изображение и видео по умолчанию

Если поле `image_url` или `video_url` у дозы препарата пустое либо файл недоступен, подставляются
`public/default-cover.png` и `public/default-video.mp4` из самого проекта. Остальные изображения и видео
лежат в `public/media`.
