# Расчёт детской дозы препарата – фронтенд

Одностраничное приложение на React 19, TypeScript и Vite 8. Компоненты интерфейса – React-Bootstrap,
маршрутизация – React Router, состояние – Redux Toolkit, запросы – axios с кодогенерацией из Swagger.

Запуск: `npm install`, затем `npm run dev`. Приложение открывается по адресу http://localhost:5173.
Кодогенерация клиента веб-сервиса: `npm run generate-api` при запущенном бэкенде.

Данные берутся из веб-сервиса `http://localhost:8080` через прокси Vite (`/api` и `/drug-dose-media`),
поэтому CORS не возникает. Если сервис недоступен, гостю показывается коллекция mock-объектов
`src/modules/mock.ts`.

## Плитка доз препаратов – `/drug_doses`

| Элемент | Назначение |
| --- | --- |
| Ползунок «от» | нижняя граница фильтра по взрослой дозе, 0–1000 мг, шаг 10 |
| Ползунок «до» | верхняя граница фильтра по взрослой дозе, 0–1000 мг, шаг 10 |
| Кнопка «Найти» | отправляет границы фильтра в запрос к веб-сервису |
| Карточка дозы препарата | изображение, название, взрослая доза, количество лайков; открывает ленту с этой дозы препарата |
| Кнопка «Удалить» | видна только у своих доз препаратов, переводит запись в статус «удалён» |

## Лента доз препаратов – `/drug_doses/feed/:drug_dose_id`

| Элемент | Назначение |
| --- | --- |
| Видео | проигрывается автоматически, без звука |
| «Взрослая доза», «Максимум в сутки» | два поля по теме, мг |
| Кнопка лайка | ставит и снимает лайк, доступна после входа |
| Кнопка «Далее» | переход к следующей дозе препарата |
| Кнопка «ещё» / «свернуть» | разворачивает описание, свёрнутое до двух строк |

## Добавление дозы препарата – `/drug_doses/draft`

| Элемент | Назначение |
| --- | --- |
| Поле «Наименование» | название новой дозы препарата |
| Поля файлов | изображение и видео дозы препарата |
| Кнопка «Далее» | создаёт черновик вместе с файлами |
| Поля черновика | краткое описание, взрослая доза, максимум в сутки |
| Кнопка «Опубликовать» | публикует черновик |

Страница доступна только после входа, гостя перебрасывает на страницу входа.

## Вход – `/users/login`

| Элемент | Назначение |
| --- | --- |
| Поля «Логин» и «Пароль» | данные пользователя |
| Кнопка «Войти» | запрашивает JWT и сохраняет его в localStorage |

## Нижняя навигационная панель

Четыре пункта: «Лента», «Добавление», «Плитка», «Вход». Гостю доступны лента и плитка. После входа
открывается «Добавление», а четвёртый пункт становится «Выход»: он отзывает токен на сервере, очищает
localStorage и сбрасывает фильтр.

## Состояния Redux

| Слайс | Что хранит |
| --- | --- |
| `auth` | признак авторизации, логин, признак модератора, ошибка входа |
| `drugDoses` | границы фильтра, список доз препаратов, признак загрузки и признак mock |
| `drugDoseFeed` | текущая доза препарата в ленте и признак загрузки |
| `drugDoseDraft` | черновик и поля формы добавления |

Доменные методы вызываются через `createAsyncThunk` и сгенерированный клиент `src/api/Api.ts`, вход и
выход – напрямую через axios без кодогенерации и thunk.
