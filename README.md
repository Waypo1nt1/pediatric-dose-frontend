# Расчёт детской дозы препарата – фронтенд

Одностраничное приложение (SPA) для просмотра доз препаратов: лента и плитка доз препаратов для гостя.
Четвёртая лабораторная работа закрывала бэкенд, эта – интерфейс на React.

Данные берутся только из коллекции mock-объектов `src/modules/mock.ts`, бэкенд в этой лабораторной не
используется.

## Стек

- React 19, TypeScript, Vite 8
- React Router 7 – маршрутизация
- React-Bootstrap 2 и Bootstrap 5 – компоненты интерфейса

Менеджер состояний и Context не используются.

## Запуск

```
npm install
npm run dev
```

Приложение открывается по адресу http://localhost:5173, стартовый маршрут перенаправляет на плитку.

## Страницы

### Плитка доз препаратов – `/drug_doses`

Список всех опубликованных доз препаратов в две колонки.

| Элемент | Назначение |
| --- | --- |
| Ползунок «от» | нижняя граница фильтра по взрослой дозе, мг (0–1000, шаг 10) |
| Ползунок «до» | верхняя граница фильтра по взрослой дозе, мг (0–1000, шаг 10) |
| Кнопка «Найти» | применяет фильтр, записывает значения в параметры адреса `min_adult_dose` и `max_adult_dose` |
| Карточка дозы препарата | изображение, название, взрослая доза в мг и количество лайков; нажатие открывает ленту с этой дозы препарата |

Значения фильтра хранятся в адресной строке, поэтому сохраняются после применения и при возврате на
страницу.

### Лента доз препаратов – `/drug_doses/feed` и `/drug_doses/feed/:drug_dose_id`

Полноэкранная карточка одной дозы препарата поверх зацикленного видео.

| Элемент | Назначение |
| --- | --- |
| Видео | короткое видео дозы препарата, проигрывается автоматически без звука |
| «Взрослая доза» | рекомендованная разовая доза для взрослого, мг |
| «Максимум в сутки» | максимальная суточная доза, мг |
| Счётчик лайков | количество лайков дозы препарата |
| Кнопка «Далее» | переход к следующей дозе препарата в ленте |
| Название и краткое описание | описание свёрнуто до двух строк |
| Кнопка «больше» / «меньше» | разворачивает и сворачивает описание |

Без указанного идентификатора открывается первая доза препарата коллекции.

### Нижняя навигационная панель

Четыре пункта: «Лента», «Добавление», «Плитка», «Вход». Доступны только «Лента» и «Плитка», остальные
два пункта появятся в следующей лабораторной работе вместе с авторизацией и добавлением доз препаратов.

## Изображение и видео по умолчанию

Если в дозе препарата поле `image_url` или `video_url` пустое либо файл по ссылке недоступен, карточка
показывает `public/default-cover.png` и `public/default-video.mp4` из самого проекта. В коллекции
mock-объектов такие случаи заданы специально: у Ципрофлоксацина нет видео, у Омепразола нет изображения.

Остальные изображения и видео лежат в `public/media` и подключаются относительными адресами, поэтому
приложение работает без бэкенда и без хранилища MinIO. Источники файлов перечислены в
`public/media/credits.csv`.

## Структура проекта

```
public/
  default-cover.png      изображение по умолчанию
  default-video.mp4      видео по умолчанию
  media/                 изображения и видео доз препаратов
  fonts/                 шрифт Inter
src/
  components/
    DoseFilter.tsx       фильтр по взрослой дозе из двух ползунков
    DrugDoseTile.tsx     карточка дозы препарата в плитке
    TabBar.tsx           нижняя навигационная панель
  pages/
    DrugDosesPage.tsx    страница плитки доз препаратов
    DrugDoseFeedPage.tsx страница ленты доз препаратов
  modules/
    mock.ts              коллекция доз препаратов и адреса медиа по умолчанию
  types.ts               тип дозы препарата, совпадает с ответом веб-сервиса
  App.tsx                общий каркас страницы с навигационной панелью
  main.tsx               маршруты приложения
  index.css              стили приложения
```

## Используемые хуки

- `useState` – значения ползунков фильтра, список доз препаратов, признак загрузки, состояние
  развёрнутого описания, подмена ссылки на изображение при ошибке загрузки
- `useEffect` – загрузка коллекции mock-объектов с имитацией задержки и очисткой таймера при
  размонтировании, пересчёт списка при изменении фильтра, установка заголовка вкладки
- `useSearchParams` – чтение и запись параметров фильтра в адресной строке
- `useParams` – идентификатор дозы препарата в ленте
- `useNavigate` – переход к следующей дозе препарата по кнопке «Далее»
- `useLocation` – выбор оформления каркаса для ленты
